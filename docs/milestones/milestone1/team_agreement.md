## Team Working Agreement
Our team will use a Slack group chat for regular communication, and Jira with GitHub for project-related tasks, issues, pull requests, and code reviews. We will check the group chat regularly and use team meetings to discuss project progress, upcoming tasks, and anything that requires group decisions.

Tasks will be divided based on the plan at the beginning of each week and sprint requirements. We will use Jira to show who has which tasks and github as a final submissions. 

If a team member encounters an issue that stops them from completing the tasks on time, they need to message either our group chat or the Team4 group chat. That way, the issue can be resolved on time. 

Before a pull request can be merged into the main branch, the code should be running smoothly and passing all the tests. Additionally 2 other team members and one of the mentors should approve this pull request.

The roles will be constantly switching depending on the team's preference and availability to complete certain tasks on time. That way, all team members would be responsible for code and documentation parts throughout the project.
